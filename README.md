# SARA AI

Advanced persistent-memory Telegram AI Agent.

SARA is designed to provide:

- Natural Telegram conversations
- Persistent long-term memory
- User profiles
- Group memory
- Conversation memory
- OpenRouter AI integration
- Multimodal understanding
- Reminders
- Proactive group conversations
- Bot-to-bot interaction
- Relationship tracking
- Personality system
- Async processing
- SQLite/PostgreSQL support

## Requirements

Python 3.11+
